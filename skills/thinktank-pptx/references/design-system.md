# Design System — シンクタンク調査報告書スタイル

pptx実装時にこのトークンをそのまま使用する。独自の色やフォントを発明しないこと。

## スライド基本設定

| 項目 | 値 |
|---|---|
| スライドサイズ | 16:9 (12192000 x 6858000 EMU / 33.87cm x 19.05cm) |
| 基本フォント | Meiryo UI (代替: 游ゴシック, Yu Gothic UI) |
| 背景 | 白 (#FFFFFF)。装飾的な背景画像・透かしは使わない |

## カラーパレット

| 役割 | 色 | HEX | 用途 |
|---|---|---|---|
| プライマリ(ネイビー) | 濃紺 | `#1F4E79` | スライドタイトル文字、表ヘッダー塗り、矢羽(強)、ナンバーボール |
| セカンダリ(ブルー) | 青 | `#2E75B6` | 強調文字(青太字)、図形アクセント、グラフ主系列、MTG縦線 |
| ライトブルー1 | 薄青 | `#BDD7EE` | 表の交互行、図形塗り(中) |
| ライトブルー2 | 極薄青 | `#DEEBF7` | ボックス背景、表の薄い塗り、図形塗り(弱) |
| テキスト | 濃灰 | `#404040` | 本文。真っ黒(#000000)より柔らかい濃灰を標準とする |
| サブテキスト | 中灰 | `#7F7F7F` | 注記、出典、補足 |
| 罫線・枠 | 薄灰 | `#BFBFBF` | 表罫線、ボックス枠線 |
| アクセント(赤) | 赤 | `#C00000` | **囲み枠専用**。最重要箇所のハイライトのみ。赤文字・赤塗りは禁止 |
| グラフ補助 | 灰 | `#A6A6A6` | グラフの比較対象・非強調系列 |

**グラデーション原則**: 表や階層図はネイビー(#1F4E79)→ブルー(#2E75B6)→薄青(#BDD7EE)→極薄青(#DEEBF7)の濃淡で階層・重要度を表現する。色相を変えるのではなく明度で見せる。

## タイポグラフィ

| 要素 | サイズ | スタイル | 色 |
|---|---|---|---|
| チャプター表記 | 11pt | 通常 | #1F4E79 |
| スライドタイトル | 18pt | 太字 | #1F4E79 |
| スライドメッセージ | 13pt | 太字 | #404040 (強調部のみ #2E75B6) |
| ボディ見出し(ボックスタイトル等) | 12pt | 太字 | #1F4E79 |
| 本文 | 10pt | 通常 | #404040 |
| 表内テキスト | 9–10pt | 通常 | #404040 |
| 注記・出典 | 8pt | 通常 | #7F7F7F |
| 表紙タイトル | 24–28pt | 太字 | #1F4E79 |

**強調ルール**: 重要ファインディングス・キーワードは `#2E75B6` の太字。下線は項目見出しの補助に限定。行間は 1.15–1.3 で詰まりすぎを防ぐ。

## レイアウトグリッド

余白とゾーニング(16:9、cm表記):

| ゾーン | 位置 | 備考 |
|---|---|---|
| 左右余白 | 各 1.0cm | コンテンツ幅 31.87cm |
| チャプター+タイトル | 上端 0.5cm から、高さ約 1.6cm | チャプターは小さくタイトル左上または直上に |
| タイトル下罫線 | ネイビー 1.5pt の水平線 | タイトルゾーンとボディの区切り。全スライド共通 |
| スライドメッセージ | タイトル罫線の直下、高さ 0.8–1.6cm | ボディ重視スライドでは1行に圧縮 |
| ボディ | メッセージ下端〜下端 1.2cm まで | |
| フッター | 下端: 左に出典/注記、右にページ番号 | |

## 表のスタイル

- ヘッダー行: 塗り `#1F4E79`、文字 白・太字
- データ行: 白と `#DEEBF7` の交互(縞)、または全行白+罫線のみ
- 罫線: `#BFBFBF` 0.5–0.75pt。外枠も同色(太枠で囲わない)
- 文字揃え: 見出し列は左揃え、評価・数値は中央/右揃え。**縦方向は資料全体で統一**(上揃え or 上下中央揃えのどちらかに固定)
- 評価記号: ◎ ○ △ ×。記号+セル背景色(濃淡)の二重符号化で一目で分かるようにする。図形装飾は控えめに(背景色のサポート役)

## グラフのスタイル

- 主系列: `#2E75B6`、比較・参考系列: `#A6A6A6`、強調1本のみ `#1F4E79`
- 凡例: 要素が多い場合はグラフ内に書き込まずグラフ下部にまとめる
- 目盛線: 薄灰の水平線のみ。枠線・縦目盛線は消す
- データラベル: メッセージに直結する値のみ表示
- グラフが複雑になる場合は「メッセージで結論を言い切り、グラフは読みたい人向けの根拠」という割り切りを許容する

## 禁則事項

- 多色(4色相以上)の使用
- 影・3D・グラデーション塗り(単色の濃淡は可)などの装飾エフェクト
- 赤の面塗り・赤文字
- スライドごとにレイアウト規則を変えること
- 1スライドにメッセージを2つ以上詰めること
