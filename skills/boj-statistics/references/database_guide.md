## 系列コードの命名規則

日銀の系列コードは一般に以下の構造を持つ（DBによって異なる）：

```
[DB識別] + [分類コード] + [品質/調整] + [地域] + [項目] + [集計方法]
```

例: `MD02MABJM2O`
- `MD02` = マネーストックDB
- `MA` = 月次
- `BJ` = 銀行計
- `M2` = M2
- `O` = 残高

コードの意味はDBごとに異なるため、正確な情報は `search_series.py --db <DB> --keyword <キーワード>` で確認するか、公式サイトのメタデータを参照してください。

## よくある質問

### Q: 使いたいデータのDBコードが分からない

日銀統計の検索サイト（https://www.stat-search.boj.or.jp/）で目的のデータを検索し、URLから確認するか、上記のDB一覧表を参照してください。

### Q: 系列コードが分からない

`search_series.py` でキーワード検索できます：
```bash
python search_series.py --db FM08 --keyword "USD"
python search_series.py --db CO  # 全系列一覧
```

### Q: データの期間（頻度）は？

`search_series.py` の出力に「頻度」列と「開始」「終了」列が表示されます。

### Q: 短観データの取得方法

短観は `CO` DBです。四半期（Q）頻度が多い：
```bash
python search_series.py --db CO --keyword "大企業"
python get_layer.py --db CO --frequency Q --start 202001
```

### Q: データポイントが多すぎてエラー

1リクエストの上限は60,000データポイント・250系列です。
`--start`/`--end` で期間を絞るか、系列数を分割してください。
