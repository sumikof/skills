# ティッカー記法ガイド

## 基本ルール

日本株のyfinanceティッカーは `{証券コード}.T` の形式。

| 形式 | 例 | 説明 |
|------|-----|------|
| `{4桁コード}.T` | `7203.T` | 東証上場銘柄（トヨタ自動車） |
| `{英数字}.T` | `285A.T` | 英字を含むコード |
| `^{シンボル}` | `^N225` | 指数 |

スクリプトでは数字のみの入力（`7203`）に自動で `.T` を付与する。

## 主要指数シンボル

| 指数名 | yfinanceシンボル | 備考 |
|--------|------------------|------|
| 日経平均株価 | `^N225` | 直接取得可能 |
| TOPIX | `1306.T` | TOPIX連動ETF（NEXT FUNDS）で代替 |
| 東証グロース市場250 | `2516.T` | マザーズETFで代替 |
| JPX日経400 | `1592.T` | JPX日経400 ETFで代替 |
| 日経300 | `1319.T` | 日経300 ETFで代替 |
| ダウ平均 | `^DJI` | 参考：米国指数 |
| S&P 500 | `^GSPC` | 参考：米国指数 |
| NASDAQ | `^IXIC` | 参考：米国指数 |

> **注意**: TOPIXはyfinanceで直接取得できないため、TOPIX連動ETF（1306.T）で代替する。ETFの値動きはTOPIXとほぼ連動するが、価格水準は異なる。

## 主要セクターETF

| セクター | ETFコード | 名称 |
|----------|-----------|------|
| 銀行 | `1615.T` | NEXT FUNDS 東証銀行業株価指数連動型 |
| 不動産 | `1633.T` | NEXT FUNDS 不動産 |
| J-REIT | `1343.T` | NEXT FUNDS J-REIT |
| 高配当 | `1489.T` | 日経高配当50 ETF |
| 半導体 | `---` | 個別銘柄で対応 |

## よくある間違いと対処法

| 間違い | 正しい形式 | 説明 |
|--------|------------|------|
| `7203` | `7203.T` | `.T`サフィックスが必要（スクリプトは自動補完） |
| `TOPIX` | `1306.T` | TOPIX指数は直接取得不可、ETFを使用 |
| `N225` | `^N225` | 指数は`^`プレフィックスが必要 |
| `Toyota` | `7203.T` | 日本株は銘柄名では検索できない |
| `7203.JP` | `7203.T` | サフィックスは`.T`（`.JP`ではない） |
