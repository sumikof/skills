## 概要

日本銀行（BOJ）の時系列統計データ検索APIを使用して、2024年のUSD/JPY月次為替レートを
取得しようとした。以下に実行したコードと結果を記載する。

## 使用したAPIの情報
================================================================================

API名称: 日本銀行 時系列統計データ検索サイト API
API提供開始: 2026年2月18日
ベースURL: https://www.stat-search.boj.or.jp/api/v1/

エンドポイント: getDataCode
対象DB: FM08（外国為替市況）
系列コード: FXERM07（東京市場 ドル・円 スポット 17時時点/月中平均）

リクエストURL:
https://www.stat-search.boj.or.jp/api/v1/getDataCode?format=json&lang=jp&db=FM08&code=FXERM07&startDate=202401&endDate=202412

パラメータ:
  format   = json
  lang     = jp
  db       = FM08
  code     = FXERM07
  startDate = 202401 （2024年1月）
  endDate   = 202412 （2024年12月）

## 実行したPythonコード
================================================================================

import urllib.request
import json

# BOJ API endpoint for FM08 (Foreign Exchange) - USD/JPY monthly data
# Series code: FXERM07 = Tokyo market USD/JPY spot rate, 17:00, monthly average
url = 'https://www.stat-search.boj.or.jp/api/v1/getDataCode?format=json&lang=jp&db=FM08&code=FXERM07&startDate=202401&endDate=202412'

print(f'Fetching URL: {url}')
try:
    req = urllib.request.Request(url, headers={'User-Agent': 'Mozilla/5.0'})
    with urllib.request.urlopen(req, timeout=30) as response:
        data = response.read().decode('utf-8')
        print('Response received:')
        result = json.loads(data)
        print(f"系列名: {result.get('name', 'N/A')}")
        print(f"系列コード: {result.get('code', 'N/A')}")
        print()
        print("日付         | USD/JPY（円）")
        print("-------------|---------------")
        for entry in result.get('data', []):
            print(f"{entry['date']}  | {entry['value']}")
except Exception as e:
    print(f'Error: {type(e).__name__}: {e}')

## エラーの原因
================================================================================

この実行環境はネットワークプロキシ経由でのアクセスが制限されており、
日本銀行（boj.or.jp, stat-search.boj.or.jp）のドメインは
「host_not_allowed」としてブロックされています。

プロキシサーバー: http://container_container_01TLdp2Szqk9pXRELKdwkJEk--...
拒否理由: x-deny-reason: host_not_allowed

stat-search.boj.or.jp および www.boj.or.jp は
許可リスト（allowed_hosts）に含まれていないため、接続が403エラーで拒否されます。

## 正しいAPI使用方法（まとめ）
================================================================================

1. エンドポイント:
   GET https://www.stat-search.boj.or.jp/api/v1/getDataCode

2. 主要パラメータ:
   - format: json または csv
   - lang: jp（日本語）または en（英語）
   - db: FM08（外国為替市況データベース）
   - code: FXERM07（東京市場ドル円スポット17時時点月中平均）
   - startDate: YYYYMM形式（例: 202401）
   - endDate: YYYYMM形式（例: 202412）

3. 完全なリクエストURL（2024年全月）:
   https://www.stat-search.boj.or.jp/api/v1/getDataCode?format=json&lang=jp&db=FM08&code=FXERM07&startDate=202401&endDate=202412

4. 代替系列コード:
   - FXUSDM: 米ドル月中平均（別系列）

5. APIマニュアル:
   https://www.stat-search.boj.or.jp/info/api_manual.pdf
