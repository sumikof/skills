CORRECT API USAGE (if network were accessible)
============================================================

The Bank of Japan Time-Series Data Search API getDataLayer endpoint is used as follows:

BASE URL: https://www.stat-search.boj.or.jp/api/v1/getDataLayer

PARAMETERS:
  - format:     csv or json
  - lang:       en (English) or jp (Japanese)
  - db:         FM08 (Foreign Exchange Rates database)
  - frequency:  M (Monthly), D (Daily), W (Weekly)
  - layer:      Comma-separated layer hierarchy values (e.g., "1" or "1,1")
  - startDate:  YYYYMM format (e.g., "202001" for January 2020)
  - endDate:    YYYYMM format (e.g., "202502" for February 2025)

FM08 DATABASE: Foreign Exchange Rates (外国為替市況)
- Contains USD/JPY spot rates and other currency pairs
- USD category is typically accessible via layer="1" or layer="1,1"

EXAMPLE REQUESTS FOR FM08 USD MONTHLY DATA:

1. Get all monthly USD data (all time):
   GET https://www.stat-search.boj.or.jp/api/v1/getDataLayer?format=csv&lang=en&db=FM08&frequency=M&layer=1

2. Get monthly USD data for specific period (2020-2025):
   GET https://www.stat-search.boj.or.jp/api/v1/getDataLayer?format=csv&lang=en&db=FM08&frequency=M&layer=1&startDate=202001&endDate=202502

3. First check layer structure via getLayerList:
   GET https://www.stat-search.boj.or.jp/api/v1/getLayerList?format=json&lang=en&db=FM08&frequency=M

4. Check metadata:
   GET https://www.stat-search.boj.or.jp/api/v1/getMetadata?format=json&lang=en&db=FM08

WORKFLOW FOR USD-SPECIFIC DATA:
1. Call getLayerList to discover FM08's layer hierarchy
2. Identify which layer value corresponds to "USD" category
3. Call getDataLayer with db=FM08, frequency=M, and the USD layer value
4. Save the CSV response

REFERENCE: https://www.stat-search.boj.or.jp/info/api_manual_en.pdf
