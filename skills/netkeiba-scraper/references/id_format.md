# netkeiba ID形式リファレンス

## レースID形式

```
YYYY MM DD VV RR
│    │  │  │  └─ レース番号（01〜12）
│    │  │  └──── 回次・日目（例: 01 = 1回1日目、12 = 1回2日目）
│    │  └─────── 日（DD）
│    └────────── 月（MM）
└─────────────── 年（YYYY）
```

ただし実際のIDは `YYYYMMDDVVRR` の12桁として連続した数字で表現される。

### 例

| レースID | 意味 |
|---------|------|
| `202506010101` | 2025年6月1日・開催コード01・1R |
| `202506050501` | 2025年6月5日・開催コード05・1R |
| `202512280512` | 2025年12月28日・開催コード05・12R |

### レースIDの取得方法

netkeibaのレースページURL からそのまま取得できる：

```
https://race.netkeiba.com/race/shutuba.html?race_id=202506010101
                                                           ^^^^^^^^^^^^
                                                           これがレースID
```

または：
```
https://db.netkeiba.com/race/202506010101/
                              ^^^^^^^^^^^^
```

## 馬ID形式

- 10桁の数字
- 馬のnetkeibaページURLから取得：

```
https://db.netkeiba.com/horse/2020104308/
                               ^^^^^^^^^^
                               これが馬ID（10桁）
```

## 騎手ID・調教師ID形式

- 5桁の数字
- 例: `01116`（C.ルメール）

```
https://db.netkeiba.com/jockey/01116/
                                ^^^^^
```

## JRA開催スケジュールの調べ方

netkeibaのトップページ（https://www.netkeiba.com/）から「開催カレンダー」を確認するか、
`get_race_list.py` で日付を指定してレース一覧を取得する。

```bash
# 今日のレース一覧
python3 scripts/get_race_list.py 20250601

# 東京競馬場のみ
python3 scripts/get_race_list.py 20250601 --venue 05
```
